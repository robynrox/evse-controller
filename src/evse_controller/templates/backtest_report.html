DP backtest

This is the technical view of Learning mode, which uses dynamic programming (DP). The first preview plan of each day is replayed against the measured grid load and frozen prices. The DP cost replaces the actual EVSE action, so it is comparable with the heuristic's net cost over the same slots. Positive delta means the DP plan would have been cheaper. This is a first-order sanity check: it does not re-solve battery constraints or supplier rewards. The solver version records which planner generation produced each day.

Re-solve with the current solver

Re-runs recorded plans using the current planner parameters and writes the results to a new job directory. First plan is fast; rolling re-solves at every slot and is much slower. The recorded runs are never modified, so jobs can be compared by solver version and by date.
