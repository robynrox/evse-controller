Battery and SoC floors

These floors apply to the shared smart-tariff controller.

Set to 30, 40 or 59 for Nissan's Leaf and e-NV200 vehicles.
Hardware/protection floor for all discharge and export, including Save Energy sessions. It cannot be set below the 25% physical reserve. Raise it (for example to 40%) to avoid draining the pack on winter days. Surplus solar can still charge the pack below this level.
Lower discretionary floor. House and grid-load coverage may spend down to here, using either conservative or aggressive discharge. The DP uses this as its single discretionary floor. Must be at or above the hard floor.
Higher discretionary floor. Planned bulk and priority exports stop here; ordinary house coverage may still use the buffer below it. Must be at or above the buffer floor. Defaults 25 / 45 / 50 for hard / buffer / bulk.

Smart tariff tuning

These settings tune the shared heuristic and DP. The defaults are sensible for most installations.

Maximum export power during Agile slots (default 7.2kW = full Wallbox capacity). Reduce if grid-limited.
State of charge loss percentage during bulk export slots. Set to 0 to use calculated value based on export power, or enter your measured value for more accurate planning.
State of charge loss percentage during load-following (non-export) slots. Used to project available SoC for export planning.
State of charge gain during a free-import session that is charging at full rate. Set to 0 to use the calculated value from charge power, charge efficiency and battery capacity.
Minimum margin required before cycling the battery or exporting. Covers marginal wear and unmodelled overheads; set 0 to optimise purely on measured efficiency. Start-up uses this margin; once discharging, the controller holds until the trade falls to zero margin, giving start/stop hysteresis without changing current levels.

Learning mode

Learning mode uses dynamic programming (DP) to plan from measured grid load and prices. Heuristic leaves the rule-based controller in control and lets Learning mode observe. Learn history is DP (recorded), using the recorded grid-load profile. Learn forecast is DP (using forecast), using the weather-driven component forecast. Off is heuristic-only and stops the observer history.

Learn history runs the DP on the recorded grid-load profile. Learn forecast runs the DP on the weather-driven component forecast; if the model or a recent weather snapshot is unavailable, that slot falls back to the heuristic. Solver version {{ solver_version }}. A bump in this version marks a planner change in future runs.
The discharge follow arc always discharges at the selected floor and follows the house load above it, using the +0.5A aggressive bias. It is planned only when the DP's expected cost improves. Default is off.
